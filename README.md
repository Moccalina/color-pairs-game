# 🎨 Color Pairs – 5-Level Memory Game

**Color Pairs** ist ein modernes, browserbasiertes Farb-Memory-Spiel mit fünf ansteigenden Schwierigkeitsgraden und sieben wählbaren Farbpaletten – entwickelt als schlanke Single-Page-Webanwendung ohne externe Frameworks.

👉 **[Jetzt direkt im Browser spielen (GitHub Pages)](https://github.io)**
🕹️ **[Auf itch.io spielen & bewerten](https://itch.io)**

---

## ✨ Features

* **5 Schwierigkeitsgrade:** Vom schnellen Einstieg in **Level 1 (9 Paare)** bis zur echten Konzentrations-Challenge in **Level 5 (96 Paare)**.
* **7 Farbthemen (Tailwind-Palette & HSL-Generator):** Spiele im bunten Mix (🌈) oder trainiere deine Farbwahrnehmung gezielt in Gelb/Orange (🟡), Rot (🔴), Lila (🟣), Blau (🔵), Grün (🟢) oder Graustufen (⚪).
* **Visuelle & barrierefreie Unterstützung:** Jede aufgedeckte Karte zeigt zusätzlich eine eindeutige Paar-Nummer (`01` bis `96`), damit auch sehr feine Farbnuancen fair unterscheidbar bleiben.
* **Lokaler Highscore:** Dein persönlicher Bestwert (geringste Anzahl an Zügen) wird pro Level automatisch im Browser (`localStorage`) gespeichert.
* **Responsive Design:** Optimiert für Smartphone, Tablet und Desktop – komplett ohne Installation oder Anmeldung.

---

## 🛠️ Tech-Stack

* **Frontend:** Reines HTML5, CSS3 (Grid & Flexbox) und Vanilla JavaScript (ES6+)
* **Hosting & Distribution:** GitHub Pages & itch.io (HTML5-Webspiel)
* **Qualitätssicherung:** Vollautomatisierte End-to-End-Tests mit Playwright
